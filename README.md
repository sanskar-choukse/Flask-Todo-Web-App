# Flask Todo Web App 📝

A simple and clean **Flask-based Todo Management Web Application** that allows users to add, update, delete, and search todos.  
The project focuses on backend fundamentals, clean UI, and live deployment.

---

## 🚀 Live Demo
🔗 https://flask-todo-web-app-7aew.onrender.com/ 

---

## 🛠 Tech Stack
- **Backend:** Python, Flask
- **Database:** SQLite, SQLAlchemy ORM
- **Frontend:** HTML, CSS, Jinja2
- **Deployment:** Render, Gunicorn
- **Version Control:** Git, GitHub

---

## ✨ Features
- Add new todos
- View all todos
- Update existing todos
- Delete todos with confirmation
- Search todos (case-insensitive)
- Clean and responsive UI
- Timestamp formatting for better readability
